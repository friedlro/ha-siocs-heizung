# SIOCS Heizung - Home Assistant App

Home-Assistant-App, die eine Fernwaermestation ueber das SIOCS-Webportal ausliest und steuert
(Raumtemperatur, Leistung, Waermemenge, Betriebsart, Korrektur).

Einrichtung: siehe [INSTALL.md](INSTALL.md). Zugangsdaten werden nur in den App-Optionen
in Home Assistant eingetragen, nie in dieses Repository.
